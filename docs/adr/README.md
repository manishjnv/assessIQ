# Architecture decision records

*Type: reference* — Index and rules for architecture decision records (ADRs).

An ADR records one decision that is hard to reverse. Format: MADR short form.

1. Copy `0000-template.md` to `NNNN-short-title.md`. Use the next free number.
2. Fill in the sections. Set the status to `proposed`.
3. Set the status to `accepted` when the owner agrees.
4. Never edit an accepted ADR. Write a new one that supersedes it.

Earlier decisions are in `docs/ROADMAP.md` and the owner decision memory. They are not copied here.
